# 吹衣深色键盘（搜狗小米风参考）· 测试版

> 当前状态：**已生成主题、已复制到红米 K70，尚待用户在手机上实测弹窗与键高。** 版本：0.1-experimental。  
> 兼容目标：同文输入法 Trime 3.3.12、吹衣带调拼音 `chuiyi_pinyin`。

## 目标与交互

主题从同文输入法官方开源默认主题改造，参考搜狗输入法小米版的**深灰配色、四行 QWERTY、键位大小、圆角和键位小字符**，未包含搜狗 APK 或版权图片。

字母键均设置：
- **轻点**：正常向 Rime 输入对应小写字母（例如 `q`）。
- **快速上滑**：直接输入键上的小字符（例如 Q 的 `1`、W 的 `2`）。
- **长按**：显示三个候选，默认高亮小字符，左右拖动高亮大写或小写，**松手才输出**。
- **边缘限制**：Trime 会根据剩余屏幕宽度自动改变候选排列；Q/P 等边缘键不保证物理左/右方向永远完全相同。已确认应用代码原生支持多选弹窗，但最终手感待实机验收。

测试重点：`Q` 小字符 `1`；`W` 小字符 `2`；试长按不动、向左、向右三种选择，观察高亮和松手结果。

## 安装

1. 下载 [`chuiyi_sogou_dark.trime.yaml`](chuiyi_sogou_dark.trime.yaml)，复制到**同文 Rime 用户目录**，不是 `schemes/` 目录。红米 K70 的实测路径：`/sdcard/Android/data/com.osfans.trime/files/rime/`。
2. 在同文输入法设置主页点击**部署**。
3. 进入**键盘样式 → 主题 → 选取主题**，选择「吹衣小米风深色·测试版」。如果主题未列出，再次部署后重启同文设置界面。
4. 进入**键盘样式 → 配色**，选择「吹衣深色」（若没有自动采用）。
5. 在「方案」选中 `chuiyi_pinyin`，回到输入框测试。键盘皮肤与输入方案是不同的设置。

## 回退与安全

- 在「键盘样式」中切回原来的主题即可回退，无需重装同文或删除用户词典。
- 本主题为**独立文件**，不会覆盖 `chuiyi_pinyin.schema.yaml`、任何词库或原有 `tongwenfeng.trime.yaml`。
- 为降低风险，不要复制搜狗 APK、私有配置、图标、贴图到此公开项目。
- 这是第一版，键高与弹窗左右触发还需要使用者确认；**不要当成已完成验收的稳定版**。
