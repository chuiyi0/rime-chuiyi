# 吹衣带调拼音 1.3

**和轻量版统一两个键：**

| | 1.2 | 1.3 |
|---|---|---|
| e / ei / ie 的四声 | `y`（被 `by`） | `t`（被 `bt`） |
| un | `t`（顿 `dt`） | `y`（顿 `dy`，和小鹤双拼一致） |

- 其他编码、词库和词频不变，没有新增重码。
- 新方案标识 `chuiyi_pinyin_1_3`，和 1.2 的用户词库分开，可以同时安装。
- 已通过打包检查和 Rime 引擎实测（50 / 50）；Windows 和手机请自行试打确认。

ZIP 已包含生成好的词库，不需要 Python。安装前请先备份 Rime 用户文件夹，步骤见 `INSTALL.md`。
