# 吹衣带调拼音：介绍与入门

**吹衣带调拼音**是吹衣OVO设计的一套 Rime 中文输入方案：**每个拼音音节用两个字母输入，部分音节按声调分配不同键位。**

它希望通过声调区分“继续／积蓄”这类无调拼音相同的词，同时让部分韵母共用键位。目前是 **1.0-dev 开发版**，欢迎试用反馈。

## 1. 先看几个例子

| 想输入 | 输入编码 | 说明 |
|---|---|---|
| 我 | `wo` | 一个音节，两键 |
| 你 | `ni` | 一个音节，两键 |
| 我们 | `womf` | 两个音节的编码连着输入 |
| 继续 | `jlxy` | jì xù |
| 积蓄 | `jixy` | jī xù；第一声与第四声使用不同编码 |
| 妈妈 | `mama` | 重复字轻声可以沿用前字编码 |
| 妹妹 | `mwmw` | 第二个“妹”也可以重复前字编码 |

输入后查看候选，**空格选择第一项，数字键选择对应候选**。词语可以连续输入，不必每个字都先上屏。

## 2. 两个字母怎么记？

**第一键通常表示声母，第二键表示韵母及声调组。** 不需要在编码后输入声调数字。

声母大多使用拼音首字母，记住以下几项即可：

| 声母 | 第一键 |
|---|---|
| zh | `v` |
| ch | `i` |
| sh | `u` |
| y、w | 保留 `y`、`w` |
| 零声母，如 a、e、ou | `o` |

例如，`ji1 → ji`，`ji4 → jl`；两个键中的 `i / l` 用来区分声调组。这里的 `1 / 4` 仅用于说明读音。

### 第二键速查

| 韵母列 | 第二键规则 |
|---|---|
| i | 四声 `l`；其余 `i` |
| u、ü | 四声 `y`；其余 `u` |
| e、ei、ie | 四声 `w`；其余 `e` |
| ian、an | 四声 `m`；其余 `j` |
| o、uo | 四声 `p`；其余 `o` |
| ai、vn（jun / qun / xun / yun） | 四声 `q`；其余 `d` |
| a、ia | 一声 `a`；其余 `x` |
| in、ua | `b`，不分声调 |
| ang、iang | `h`，不分声调 |
| ing、uai | `k`，不分声调 |
| eng | `g`，不分声调 |
| ao | `c`，不分声调 |
| en | `f`，不分声调 |
| ong（含 iong） | `s`，不分声调 |
| iu、ou | `z`，不分声调 |
| un | `t`，不分声调 |
| ui | `v`，不分声调 |
| uan | `r`，不分声调 |
| iao、uang | `n`，不分声调 |

**“其余”包括轻声。** 部分拼音有专门安排，以[完整编码表](MATRIX.md)为准，尤其记住：

- `lv`（吕、绿一类）：第一键用 `f`，四声 `fl`，其他声调 `fi`。
- `nve / lve`（虐、略一类）：与 `nuo / luo` 共用相应编码组。
- `jue / que / xue / yue`：按 uo 列选第二键。
- `er`：与 `ri` 共组，四声 `rl`，其他声调 `ri`。
- 独立音节 `o`：四声 `op`，其他声调 `oo`；`ou` 始终是 `oz`。

## 3. 轻声怎么输入？

普通轻声使用表中的“其余”组。例如，“我们”的“们”用 `mf`。

**相邻两个字相同，后字读轻声时，已收录的词可以重复前字编码：**

- 妈妈：`mama`，也保留默认轻声码 `mamx`。
- 妹妹：`mwmw`，也保留默认轻声码 `mwme`。
- 爸爸：`bxbx`，两种方式原本就相同。

这个兼容规则已加入现有词库中的相应词条；新造词、未收录词暂不保证自动生效。

## 4. 怎么安装？

它是一套**输入方案**，需要先安装 Rime 客户端：电脑用小狼毫，Android 用支持 Rime 方案的中州韵／同文客户端。

**先向作者取得 ZIP 安装包。** GitHub 仓库是源码；若直接下载源码，需要先按[生成说明](README.md#可复现生成)生成词库，不能只复制仓库里的两份 YAML。

### Windows 小狼毫

1. 解压安装包。右击小狼毫托盘图标，打开“用户文件夹”，先备份配置。
2. 将 `chuiyi_pinyin.schema.yaml`、`chuiyi_pinyin.dict.yaml` 和整个 `chuiyi_pinyin_dicts` 文件夹复制进去。
3. 在已有 `default.custom.yaml` 的 `patch → schema_list` 下追加一项，保留原有方案：

```yaml
    - schema: chuiyi_pinyin
```

如果原来没有 `default.custom.yaml`，可以新建，内容为：

```yaml
patch:
  schema_list:
    - schema: chuiyi_pinyin
```

4. 托盘右键选择“重新部署”。完成后按 **Ctrl + `**（Tab 上方的反引号键），选择“吹衣带调拼音 1.0-dev”。
5. 输入 `mama`、`mwmw`、`jlxy`，检查是否出现上面的候选。

Android 的文件放置和方案导入入口因客户端版本不同，请参照[详细安装说明](INSTALL.md)。Android 实机尚待验证。

## 5. 建议怎么开始练？

先练“我、你、我们”，再练“妈妈、妹妹”，最后比较 `jlxy → 继续` 与 `jixy → 积蓄`。不必一次背完整张表，不熟的音节查编码表即可。

如果打不出来，先确认已切到 **1.0-dev 新版**，再检查词库文件夹是否完整、是否重新部署。反馈时提供“想打的字词＋实际编码＋出现的候选”，便于定位。
