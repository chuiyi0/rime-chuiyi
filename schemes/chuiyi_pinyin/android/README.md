# 安卓专用候选补丁（可选）

适用：同文 Trime 3.3.12 + 吹衣带调拼音 1.2。**不修改原始词库或 Windows 方案。**

## 目的

双拼码每字两键。第二字只输入第一键时（例如 `wxm`）有时看不到候选。
本目录的 `chuiyi_pinyin_1_2.custom.yaml` 会在现有音节编码规则后追加**单字音节首码简拼**规则，尝试让 `wxm` 提前出现以 `m` 开头的第二音节候选。

## 安装（先备份）

1. 在手机同文的 shared 用户目录中找到 `chuiyi_pinyin_1_2.schema.yaml`。
2. **如果已有 `chuiyi_pinyin_1_2.custom.yaml`，不要覆盖**；请把本补丁的 `"speller/algebra/+"` 合并进已有 `patch:`。
3. 否则把本目录的同名 `.custom.yaml` 放到该位置，然后在同文内**重新部署**。
4. 依次试打 `wx`、`wxm`、`wxmf`，另用曾经出现空白候选的三键编码复测。
5. 逐码简拼可能造成某些三键串的分段变化（Rime 双拼的已知权衡）。如出现错分段，恢复备份或移除本补丁并重新部署。

> 目前只有文件与规则层面的检查；尚未在 Redmi K70 上进行 Rime 引擎或实际候选回归测试，不保证所有三键都会出现合理候选。

## 皮肤工具栏

另见 [同文皮肤集合](../../../themes/trime/README.md)：12 套皮肤均加入**空输入常驻工具栏**（菜单／编辑／剪贴板／表情／设置），输入中自动显示正常候选。编辑键盘含复制、粘贴、剪切、光标移动等动作。
仅新增工具栏和一套独立编辑键盘；原 26 键、数字键盘、键位高度、上滑、长按、底部留白与配色不改。
将选择的 `.trime.yaml` 放入手机同文 shared 目录，在设置里切换到它并按需重新部署。
