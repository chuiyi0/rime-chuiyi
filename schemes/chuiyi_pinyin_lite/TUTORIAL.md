# 快速抽样教程

切换到“吹衣带调拼音轻量版 1.0.0”，在中文输入框中测试以下编码。表中的拼音是用于说明的目标读音，不要求实际输入数字声调。

| 按键 | 对应读音示例 | 检查点 |
|---|---|---|
| `yi` | 一、衣等 | 非第四声使用 i |
| `yp` | 意、义等 | 第四声使用 p |
| `ww` | 无、吴等 | u 韵母非第四声 |
| `wu` | 物、务等 | u 韵母第四声 |
| `oe` | 额等 | e 韵母非第四声 |
| `oy` | 饿等 | e 韵母第四声 |
| `be` | 杯、憋等 | 重复编码按候选显示 |
| `by` | 被、别等 | 第四声替代键 |
| `jw` / `jv` | 居等 | 检查矩阵里 ju 的两种合法编码 |
| `no` | 挪、虐等 | 检查 nuo/nve 同码候选 |
| `lo` | 罗、略等 | 检查 luo/lve 同码候选 |

本版只进行代表性抽样，不宣称完整穷举测试。若某个按键无候选，请记录“输入编码、预期词、实际候选”，便于定位。
