# 吹衣带调拼音轻量版 1.1.0

这是独立的 Rime 双拼方案，按作者提供的 [MATRIX.md](MATRIX.md) 编码，零声母按 [ZERO_INITIALS.md](ZERO_INITIALS.md) 覆盖；不会覆盖仓库里的吹衣带调拼音 1.2.x。

## 设计规则

- 每个音节输入两个按键：第一键来自左侧声母编码列，第二键来自顶部韵母编码行。
- 顶部编码为空时，继承左侧最近一个非空的韵母编码。
- 顶部若为两个字母（例如 `ip4`、`wu4`、`ey4`），第一个字母用于非第四声，第二个字母仅用于第四声；数字 `4` 是说明标记，不用输入。
- 顶部为一个字母时，各声调使用同一个韵母键。
- 原矩阵中的重复拼音、重复编码及特殊拼写均予以保留，不擅自换键。

## 示例

| 拼音 | 输入编码 |
|---|---|
| `yi1` | `yi` |
| `yi4` | `yp` |
| `wu1` | `ww` |
| `wu4` | `wu` |
| `e1` | `ee` |
| `e4` | `ee` |
| `bei1` | `be` |
| `bei4` | `by` |

编码有意存在同码情况；输入后由 Rime 按词库显示候选。完整映射见 `mapping.tsv`。
