# 吹衣方案一：并击实验版

> 状态：实验功能。标准版 `chuiyi_1` 不变；先在 Windows 小狼毫测试。Android 同文的虚拟键盘并击行为尚未实机验证。

## 原理

本实验版使用 Rime 的 `chord_composer` 处理器：同时按下的键会先转换成现有方案的两字母编码，再交给原有词库选词。逐个输入字母仍然可用，因此可以在同一方案中混合使用逐键输入和并击。

## 并击规则

并击键位包含空格和字母。字母按 a–z 排序：

- **编码两字母按字母顺序排列**：同时按下两个字母。例如 `jx` 用 `J+X` 并击。
- **编码两字母顺序相反**：同时按下空格和两个字母。例如 `xj` 用 `Space+J+X` 并击。
- **两个字母相同**：同时按下空格和该字母，例如 `aa` 用 `Space+A`。只有当前编码中确实存在的码才会有候选。
- **空格单独按下**：仍用于选择首选候选。
- **逐键输入**：仍可像标准方案一样逐个输入两个字母。

所有参与并击的键必须有按键时间重叠；依次按下和松开会被当作普通逐键输入。反序编码使用空格作并击辅助键，不是先按空格再按字母。

## 测试例子

| 目标编码 | 并击方式 |
| --- | --- |
| `jx` | 同时按 `J+X` |
| `xj` | 同时按 `Space+J+X` |
| `wr` | 同时按 `Space+R+W` |
| `aa` | 同时按 `Space+A`（若该编码有效） |

并击输出的仍是编码，不是直接提交汉字；候选排序和选词仍由吹衣方案原有词库处理。

## 兼容性与限制

- 最多需要同时按下 3 个键；键盘需要支持对应组合，部分笔记本键盘可能存在按键冲突。
- 建议先在 Windows 小狼毫中选择“吹衣方案一（并击实验）”测试。
- Android 同文及其他触屏键盘是否能可靠提供重叠的按键事件，尚未验证；手机优先继续使用“吹衣方案一”标准版。
- 若并击无响应或候选异常，可切回标准版。标准版的编码、词库和按键行为没有启用并击处理器。

技术依据：Rime 的 `chord_composer` 处理器及[宫保拼音并击说明](https://github.com/rime/home/wiki/ComboPinyin)。
