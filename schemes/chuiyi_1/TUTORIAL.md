# 吹衣带调双拼教程

每个音节输入两个字母，词语连续输入，不加空格。

## 韵母对应表

| 韵母 | 第二个字母 |
| --- | --- |
| i | i、o、p |
| u、ü | u、y、t |
| e、ei、ie | e、w、q |
| an、ian | j、m |
| ao | c |
| ing、uai、eng | g、k |
| in、en | f |
| ang、iang | h、l |
| a、ua、ia | a、x |
| o、uo、üe | r |
| ong、iong | s |
| iu、ou | z |
| un | b |
| ai、uan | d |
| iao、uang | n |
| ui | v |

## 声调

- 三个字母：依次对应一声、二三声、四声。轻声兼容第一个和第三个。
- 两个字母：依次对应一二声、三四声。轻声两个都兼容。
- 一个字母：所有声调共用。

例如 `ji=ji1/5`，`jo=ji2/3`，`jp=ji4/5`；`jj=jian1/2/5`，`jm=jian3/4/5`。

## 特殊声母与拼音

其余声母保留原字母。

- `v=zh`
- `i=ch`
- `u=sh`
- `fi=lv`（lü）：这里的第二码 i 与其他 i 韵母一样按 i/o/p 分声调，即 `fi=lv1/5`、`fo=lv2/3`、`fp=lv4/5`。
- `lr=lve`（lüe）：各声调共用。

## 输入示例

- `wr → wo → 我`
- `wrmf → women → 我们`
- `jpxt → ji4xu4 → 继续`
- `jixt → ji1xu4 → 积蓄`
- `qj → qian2 → 前`

候选出现后，按空格选第一项，或按数字选择其他项。
