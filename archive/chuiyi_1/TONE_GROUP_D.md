# D 方案：局部韵母声调分组统计

> 状态：已用仓库快照完成可复现的词库统计（2026-10-17）；实际双拼编码重码和真实输入效果仍待实测。本文记录设计 D，不修改当前方案一的键位、词典或轻声兼容规则。

## 设计规则

仅 `i / u / e / ie / ei` 五类韵母区分声调：

| 声调 | D 分组 |
| --- | --- |
| 1 声 | 1 |
| 2、3 声 | 23 |
| 4 声、轻声（数字 5） | 45 |

其余韵母完全不区分声调。D 的轻声只归入 45 组，不额外兼容 1 组。现行方案一仍有其他韵母分组、轻声双编码等规则，不能直接把其编码函数用于本统计。

按标准拼音字母形式归韵：`zi/chi/shi` 等归 `i`，`yi→i`、`ye→ie`、`wu→u`；`ju/qu/xu/yu` 的韵母归 `ü`（脚本内部写作 `v`），不归 `u`。`wei→ui`、`you→iu`，也不拆成 `u` 或 `i`。这里不是更细的语音学元音分类。

## “2500 常用词”的近似口径

1. 以本仓库 [`sources/upstream/base.dict.yaml`](sources/upstream/base.dict.yaml) 的雾凇基础词库为候选；不是官方常用词表，也不是实时语料频率。
2. 只取至少两个汉字、拼音音节数与字数相等的词，包含双字及更长词；不含单字、数字、拉丁字母或标点词条。汉字范围见脚本 `han_word`。
3. 按字形去重，同词不同读音取最大权重作为排序权重，不累加；按权重降序取前 2500 个词，同权重按 Unicode 字符顺序。先选词，再匹配带调数据，不因缺注音而补选低排名词。
4. 带调读音来自 [`chuiyi_dicts/base.dict.yaml`](chuiyi_dicts/base.dict.yaml)，只保留无调拼音与雾凇源词条匹配的读音，合并同词的所有匹配读音。本次 2500 个词的所有源拼音均有匹配，缺失数为 0；这不证明词典覆盖了现实中的一切读法。
5. 保留匹配数据中已有的本调、变调和轻声，不额外推断或穷举多音组合。雾凇权重只用于选样，以下词对计数不按权重加权。

选中词按排名逐行拼接并保留末尾换行，其 UTF-8 SHA-256 为 `9054e51f638d57228eaa34b361c603549c2b557a5e1d00217ccab2cde2b5db15`，入选最低权重为 434898。结构化结果及 D 仍重合的词对见 [`TONE_GROUP_D_RESULTS.json`](TONE_GROUP_D_RESULTS.json)。

| 指标 | 本次词库统计 |
| --- | ---: |
| 入选词数 / 源拼音覆盖完整词数 | 2500 / 2500 |
| 无调拼音相同的不同词对 | 81 |
| 完全区分 1/2/3/4/5 声仍重合 | 17 |
| 完全区分五声可消歧 | 64 |
| D 分组仍重合 | 40 |
| D 分组可消歧 | 41 |
| D 消歧比例（41 / 81） | 50.62% |

计数单位是**不同字形的无序词对**，不是重码组数、词数或击键次数。若一组有 n 个词，贡献 n(n−1)/2 对；同一词对即使有多个相同无调读音也只计一次。只要双方任一收录读音的完整签名相同，就判为仍重合；不能只挑选一种读法显示消歧。

无调签名保留完整拼音、删除每音节末尾声调；五声签名保留原始带调拼音；D 签名保留完整拼音，只在指定五类韵母上附加 1/23/45 分组，其余声调抹去。因此这里衡量的是**原本无调同音的词对能否靠 D 分组区分**，尚未计算不同拼音映射到相同双拼键位后新增的碰撞。

此前讨论中的 `81/66/41` 和 `62.1%` 未经充分核验，不能作为实测结论引用。本表数字全部由本次脚本重新计算；81 和 41 的相同不构成对旧统计的验证。当前口径下五声可消歧数是 64，D 消歧比例的分母是全部 81 对；若另问 D 保留了多少五声消歧能力，则为 41/64 = 64.06%，两种比例不得混用。

## 复现与待实测事项

Python 3，无额外依赖，在仓库根目录运行：

```text
python archive/chuiyi_1/tools/tone_group_stats.py
```

更新机器可读结果：

```text
python archive/chuiyi_1/tools/tone_group_stats.py --output archive/chuiyi_1/TONE_GROUP_D_RESULTS.json
```

脚本输出输入指纹、选样指纹、覆盖缺失明细及词对统计。输入变更后应重新运行，并同步核对本文；若覆盖不足，输出仅代表覆盖完整词的子样本，不可冒充完整 2500 词结果。

仍待实测：D 的具体键位编码及跨拼音重码、轻声兼容策略的对照、词频加权或真实输入频率、人工核对多音词及变调读音。本文结果不能外推为真实输入误选率或正式大词库消歧率。原有[测试词库按韵母统计](TONE_COLLISION_STATS.md)使用不同样本和指标，不能与本表直接拼接比较。
