# 快捷主题面板

点键盘顶部的 🎨 打开快捷主题面板，一键切换整套皮肤（不只是换颜色）。点「全部主题」会打开同文自带的主题选择器。

当前收藏 8 套：樱花糖、冰川蓝、薄荷茶、深海蓝、奶杏、暮光紫、黑曜夜、琥珀纸。

[返回皮肤说明](README.md)

## 修改收藏的主题

同文 3.3.12 不能在手机上直接保存快捷主题的增删，所以收藏列表单独存在 `tools/favorite_themes.json` 里，用电脑脚本改好再推送到手机。

准备：电脑装好 Python 3 和 [adb](https://developer.android.com/tools/adb)，手机用 USB 连接电脑并打开「USB 调试」。脚本用 PyYAML 检查语法，没装的话先运行 `pip install pyyaml`。

1. 编辑 `tools/favorite_themes.json` 里的 `favorites`：填 `01`～`12` 的编号，最多 8 个（可以更少），顺序就是面板里的显示顺序。
2. 在 `themes/trime/tools/` 下运行 `python update_favorites.py`。脚本会先备份手机上现有的皮肤，**只改快捷主题按钮**，其他布局不动；推送前会检查所有文件的 YAML 语法，有错就停下，不会改手机上的文件。
3. 在同文「键盘样式 → 主题」里先切到别的主题，再切回来。只点「部署」不一定能刷新当前皮肤。
4. 想同步到 GitHub，把更新后的皮肤文件提交到本目录。

## 返回键的位置

Trime 3.3.12 的顶部左上角按钮不能随当前键盘页面改变动作，所以：

- 编辑页：内容区左上第一个键是「← 返回」。
- 表情页：顶部有一条固定的返回栏。
- 数字、符号、主题页：底部导航和主键盘位置、宽度一致。
