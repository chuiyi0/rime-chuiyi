# 吹衣主题快捷面板（Trime 3.3.12）

顶部 🎨 打开彩色快捷主题面板。当前收藏 8 套：樱花糖、冰川蓝、薄荷茶、深海蓝、奶杏、暮光紫、黑曜夜、琥珀纸。选择后切换整套皮肤（不是单纯修改色板）。「全部主题」打开同文内置主题选择器。

## 增加或减少快捷主题

手机端 Trime 3.3.12 的皮肤配置无法直接保存用户增删的快捷主题，因此把收藏项单独保存为 `favorite_themes.json`。在 Windows 连接手机并开启 USB 调试后：

1. 编辑 `favorite_themes.json` 的 `favorites` 数组，主题编号 `01` 至 `12`，最多 8 个，可少于 8 个，顺序即显示顺序。
2. 运行 `python update_favorites.py`。脚本先备份手机中 13 套皮肤的当前文件，再**仅修改主题快捷项**，其他布局保持不变。
3. 在同文「键盘样式 → 主题」中先切换到其他主题，再切回原主题（仅点「部署」不一定刷新当前皮肤）。如果还需要同步 GitHub，请把更新后的皮肤上传，或者请 ChatGPT 同步。

本目录文件可复制到 `E:\GPT_file\TrimeUI_2026-11-08_v5\` 中使用。当前电脑里已保存独立收藏清单与脚本。

## 菜单和返回说明

顶部左上角恢复旧版「更多／菜单」，右上角收起键盘。**Trime 3.3.12 的皮肤层不支持根据当前键盘自动改变顶部左按钮动作**。因此编辑页在内容区左上第一键设「← 返回」，表情页则将固定返回栏放到顶部；这不是同一个全局顶部按钮。数字/符号/主题页的底部导航与主键盘保持同一位置和宽度。

底部比例：符 16%、123 14%、逗号 9.75%、空格 24%、句号 9.75%、中/英 11%、回车 15.5%。空格显示「吹衣拼音」。

**这版只做计划级布局检查，手机已安装并触发部署；未进行实际按键验收，由用户自行验证。**

## 2026-11-08 修复记录

此前所有皮肤在「完整符号」末尾出现 YAML 列表缩进错误，导致新皮肤无法编译、手机持续显示旧版本。现已修正 13 套手机皮肤及 GitHub 基础模板，配置版本从 3.0 更新为 3.1，且已在手机上验证 07/08 主题正常编译与切换。以后通过脚本增删收藏时，自动提升 `config_version`，并在上传前校验所有文件的 YAML 语法，防止同类问题。

## 2026-11-08 v3.2 图标与返回限制

顶部主题入口改为与其他工具统一的单色 `ic@palette_outline` 图标，去除粉紫色单独背景。已在 Redmi K70 上实际显示成功，并同步全部 13 套皮肤。配置版本 `3.2`。

**重要限制：**Trime 3.3.12 的 `AlwaysUi` 主按钮（`tool_bar.primary_button`）在皮肤配置层不能根据 `preset_keyboards` 当前页变更点击动作或图标。用户在主键盘打开「编辑」或「主题」键盘时，左上角主按钮仍会显示菜单点点；页面内另有返回键。要让**同一顶部位置**在主键盘显示菜单、子页面显示返回并返回上一键盘，必须修改同文原生 Android 代码并另行打包安装，不能宣称通过 YAML 已修复。涉及替换 Android 应用时应先备份用户数据和确认签名/升级安装方案。
